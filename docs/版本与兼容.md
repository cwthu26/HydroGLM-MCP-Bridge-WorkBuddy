# 版本与兼容

当前通用版：**v1.0.1（2026-11-20）**。更新内容见 [发布说明](../RELEASE_NOTES.md)。

| 项目 | 原版 | 通用版 |
|---|---|---|
| 仓库名 | HydroGLM-Codex-MCP | HydroGLM-MCP-Bridge |
| 主要用途 | Codex 安装、注册及自动选用 | 多客户端本地 stdio 接入 |
| 默认客户端注册名 | `hydroglm` | `hydroglm_bridge` |
| 工具名 | `ask_hydroglm` | `ask_hydroglm` |
| 参数 | `question`、`agent`、`session_id`、`web_search`、`enable_thinking` | 五个参数保持兼容 |
| 密钥变量、文件格式 | 原有格式 | 保持兼容 |
| 安装器是否改客户端配置 | 按原版流程 | 只生成片段，由用户合并 |

原仓库地址：[HydroGLM-Codex-MCP](https://github.com/LIMING-gloria/HydroGLM-Codex-MCP)。建议新建独立的 `HydroGLM-MCP-Bridge` 仓库，保留旧仓库名、文件和下载方式；不要把旧仓库直接重命名为通用版。

已有用户继续运行旧目录下的 `server.py`，不需要迁移。新用户按通用版文档配置。两个项目可以共存；同一客户端启用两份服务可能显示重复工具，可选用其一，或按服务器名称区分。

## 验证范围

- 实现并检查 `2024-11-05`、`2025-03-26`、`2025-06-18` 初始化协商和工具子集；未声明完整规范认证。客户端请求其他版本时，返回本服务支持的 `2025-06-18`，是否继续连接由客户端判断。
- 提供 stdio JSON-RPC 初始化、工具发现、调用分派和错误响应的本地测试。
- 配置生成器输出 JSON/TOML 片段，并测试旧版注册项不会被它改写。
- WorkBuddy / Claude Desktop 的说明依据官方文档整理，未做对应 GUI 实测。
- Windows 密钥保存分支做了离线模拟测试；跨平台 GitHub Actions 工作流已提供，实际结果以 GitHub 运行记录为准。
- API 真正可用性取决于用户密钥、网络、上游状态及客户端等待限制；离线测试不代表在线可用性验证。
