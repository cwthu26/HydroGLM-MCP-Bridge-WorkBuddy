# 按任务选用建议

以下文字可加入支持自定义指令的客户端。它是使用建议，不是已安装的 Skill，也不能保证客户端每次都会调用工具。

适用前提：服务器已启用、`ask_hydroglm` 对当前对话可用、已保存对应模型密钥，且客户端允许调用外部服务。详细原理和场景判断见 [MCP 原理与调用场景](MCP原理与调用场景.md)。

> 当任务涉及水文、水资源、水库调度、梯级水电、洪水演算、水动力等领域，并需要专业知识、方法比较或专业判断时，考虑调用 HydroGLM MCP 的 `ask_hydroglm`。普通编程、文件读取或不相关任务不必调用。专业咨询由 HydroGLM 返回文本建议；本地文件处理、代码执行、仿真、绘图及结果校验由宿主工具完成。重要公式、数值和结论应独立验证。用户明确不使用外部服务时不调用，未经允许不将内部或敏感文件内容写入问题。调用失败时如实说明，不能把未执行的代码或建议描述为实际计算结果。

如果客户端同时启用旧版和通用版，明确选用 `hydroglm_bridge` 下的工具。需要核验是否调用时，检查客户端的真实工具记录，而非只看自然语言回答。

需要 plus 时，显式传入 `agent="HydroGLM-plus"`。不传 `agent` 时默认选用 `HydroGLM`。
