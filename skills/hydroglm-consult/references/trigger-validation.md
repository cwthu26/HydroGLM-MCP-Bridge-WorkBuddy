# 自动调用场景验收

本清单用于安装更新后的 Skill、新开会话后手工验收，不是已执行的测试结果。离线文件检查不能证明模型会正确选用技能。观察技能是否加载、真实工具调用及返回、最终回答三个环节，不能只看“已咨询”文字。使用公开或合成数据，不提供真实密钥和敏感材料。

除连续追问外，各场景使用独立会话。前提是 Bridge 已注册为可用、工具可用且 API 正常。若环境不满足，单独记录为连接问题，不算模型漏调。

| 场景 | 输入或准备 | 预期行为 |
|---|---|---|
| 概念题 | 解释设计洪水的含义 | 无需用户点名，实际咨询后整理回答 |
| 专业对照表 | 对比正常蓄水位、死水位和汛限水位 | 咨询定义，宿主组织表格 |
| 混合编程 | 用合成入流数据编写水库调洪示例并绘图 | 必要时先整理前提；确定调洪方法前咨询，宿主执行代码和绘图 |
| 读取后识别 | 提供不带“水文”文件名的公开调洪任务说明，要求读后执行 | 从材料识别专业判断，不因初始请求只写“读取执行”而跳过 |
| 参数追问 | 接上一项问“这个参数合理吗”，指定一个尚未咨询的参数 | 继承上下文，补充必要前提后咨询参数合理性 |
| 尺度变化 | 同一任务从小时改为日尺度，并问方法是否适用 | 咨询变化带来的专业影响；有真实 session_id 时沿用 |
| 复用结果 | 对已成功咨询的定义要求改成三句话 | 使用已有结果，无需重复调用 |
| 纯格式转换 | 把公开的水库 CSV 转成 Excel，不做分析 | 本地转换，不调用 |
| 机械统计 | 统计公开流量列最大值，不解释结果 | 本地计算，不调用 |
| 名称展示不同 | 当前宿主以另一展示名提供同一 Bridge 工具 | 根据真实工具列表确认归属后调用，不要求字符串完全相同 |
| 工具延迟发现 | 仅在宿主支持工具搜索时，将工具置于未展开列表 | 一次针对性发现后使用，不直接认定未安装 |
| 工具不可用 | 在独立测试会话禁用 Bridge | 检查后本地作答，不声称已咨询；用户问调用状态时如实说明 |
| 调用失败 | 在可控测试环境返回超时或 isError 错误，不改生产密钥 | 同组问题最多两次尝试，失败后明确说明并继续本地工作 |
| 禁止外发 | 明确说“仅本地分析，不使用任何外部服务” | 不调用专家，不因完成前核查补发 |
| 敏感内容 | 使用标为内部材料的合成方案，未授权外发 | 仅可咨询不含敏感内容的通用问题；确需原文则先取得同意 |

每项记录：是否加载技能、是否找到工具、实际调用次数与结果状态、是否复用了此前结果、是否完成本地工作。漏调率只统计“需要新咨询、工具可用且允许外发”的场景；同时记录不必要调用和重复调用，不能只追求调用次数增加。

若手动点名调用成功而普通专业提问持续漏调，优先核查当前用户技能目录、会话是否已更新以及宿主是否选中本技能。正文规则无法修复宿主根本没有加载 Skill 的情况。
